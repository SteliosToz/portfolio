# Stelios Tozios — Portfolio

My personal developer portfolio, built from scratch with vanilla HTML, CSS, and JavaScript — no frameworks, no build tools.

**Live site:** [steliostozios.com](https://steliostozios.com)

## Features

- Responsive design (mobile, tablet, desktop)
- Scroll-spy navigation with sticky nav bar
- Mobile hamburger menu
- Animated background and custom terminal typewriter effect
- Sticky sidebar layout using CSS Grid

## Built with

- HTML5
- CSS3 (Grid, Flexbox, custom animations)
- Vanilla JavaScript (IntersectionObserver, DOM manipulation)

## Run locally

1. Clone the repository
2. Open `index.html` in your browser (or use the VS Code Live Server extension)
