About

Hi, I'm Stelios — a junior developer based in Thessaloniki. I originally trained in Digital Marketing, but a lifelong curiosity for computers, combined with a genuine interest in building things, pulled me toward programming instead.

I completed a two-year vocational program in web development, covering a wide range of web and software technologies — from HTML, CSS and JavaScript to Python, C and C++, along with database management. That mix gave me a solid foundation in both front-end web development and core programming concepts, and I'm still exploring which direction excites me more — for now, I'm happy building in both.

Outside of code, I play the bouzouki — proof that building things, whether with strings or with syntax, has always been part of how I think.

Projects

Stocle

Stocle started as an assignment during my web development studies — but I kept building after the course ended, turning it into a fully independent project. I designed and built the entire site solo: choosing the minimal menswear niche, developing the WordPress and WooCommerce foundation, and shaping the "less is more" visual identity from scratch using Astra and Elementor. The result is a complete, live e-commerce store — product catalog, blog, and contact system included — that goes well beyond the original course requirements.
