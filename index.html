About

Hi, I'm Stelios — a junior developer based in Thessaloniki. I originally trained in digital marketing, but a lifelong curiosity for computers, combined with a genuine interest in building things, pulled me toward programming instead.

I completed a two-year IEK program covering a wide range of web and software technologies — from HTML, CSS and JavaScript to Python, C and C++, along with database management. That mix gave me a solid foundation in both front-end web development and core programming concepts, and I'm still exploring which direction excites me more — for now, I'm happy building in both.

Outside of code, I play the bouzouki — proof that building things, whether with strings or with syntax, has always been part of how I think.
